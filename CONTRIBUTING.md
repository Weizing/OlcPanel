# Contributing to OlcPanel

Спасибо за интерес к проекту! Мы приветствуем любой вклад.

## Как внести вклад

1. **Fork репозитория**
2. **Создайте feature branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Commit изменения**
   ```bash
   git commit -m 'Add some amazing feature'
   ```
4. **Push в branch**
   ```bash
   git push origin feature/amazing-feature
   ```
5. **Откройте Pull Request**

## Тестирование

Перед отправкой PR убедитесь что:
- [ ] Код работает локально
- [ ] Docker образы собираются без ошибок
- [ ] Нет конфликтов с main веткой
- [ ] Добавлена документация для новых функций

## Сообщения о багах

При создании issue укажите:
- Версию OlcPanel
- Версию Docker
- Шаги для воспроизведения
- Ожидаемое поведение
- Фактическое поведение
- Логи (если применимо)

## Предложения функций

Перед созданием issue с предложением:
- Проверьте что такой функции еще нет
- Опишите use case
- Объясните почему это полезно

Спасибо за вклад! 🎉
